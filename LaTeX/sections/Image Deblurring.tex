\subsection{Potential Application: Image Deblurring}

Image deblurring addresses the recovery of a sharp image $y \in \mathbb{R}^n$ from a blurred and possibly noisy observation $x \in \mathbb{R}^n$, where $n$ represents the total number of pixels. This task is formulated as a parametric convex quadratic programme
\begin{align}
    \min_{y} \quad & \| A y - x \|_2^2 + \lambda \| y \|_1 \\
    \text{s.t.} \quad & 0 \leq y \leq \mathbf{1},
\end{align}
with $A \in \mathbb{R}^{n \times n}$ denoting a blurring operator, typically a circulant matrix approximating a two-dimensional Gaussian convolution kernel, $\lambda > 0$ a regularisation parameter trading off data fidelity and sparsity, and $\mathbf{1}$ the all-ones vector. The parameter $x$ encapsulates the observed blurry image, while the decision variable $y$ corresponds to the sought sharp image stacked column-wise from its matrix representation. This structure aligns with the general parametric framework, where the objective $f(y, x) = \| A y - x \|_2^2 + \lambda \| y \|_1$ is smooth and strongly convex under the box constraints $C(x) = \{ y \in \mathbb{R}^n : 0 \leq y \leq \mathbf{1} \}$, ensuring a unique solution $y^*(x)$.

To apply split conformal prediction in this setting, partition an exchangeable dataset $\{X_i\}_{i=1}^N$ of parameters $X_i = x_i \in \mathcal{X} \subseteq \mathbb{R}^n$, drawn from the unknown distribution $\mathbb{P}$ over $\mathcal{X}$, into a training set $S_T = \{ x_i : i \in \mathcal{I}_T \}$ of size $m_T$ and a calibration set $S_C = \{ x_j : j \in \mathcal{I}_C \}$ of size $m_C = N - m_T$. Train a predictive model $\hat{\mu}: \mathcal{U} \to \mathbb{R}$ on $S_T$ to approximate the performance metric $\phi^K: \mathcal{X} \to \mathbb{R}_+$, defined as the fixed-point residual $\phi^K(x) = \| T(y^K(x), x) - y^K(x) \|_2$ after $K$ iterations of the first-order method, where $y^{k+1}(x) = T(y^k(x), x)$ encodes the update rule with initialisation $y^0(x) \in Z \subseteq \mathbb{R}^n$ and $T: \mathbb{R}^n \times \mathcal{X} \to \mathbb{R}^n$ the associated operator.

For each calibration point $x_j \in S_C$, compute the true residual $V_j = \phi^K(x_j)$ by executing the $K$-step solver, and evaluate the nonconformity score $R_j = | V_j - \hat{\mu}(U_j) |$ using the fixed model $\hat{\mu}$, where $U_j$ denotes the feature representation of $x_j$. The nonconformity measure $\mathcal{A}: \mathcal{X}^{m_C + 1} \to \mathbb{R}^{m_C + 1}$ thus yields the vector of scores $[R_1, \dots, R_{m_C}, R_{m_C + 1}]^T$ for a test parameter $X_{N+1} = (U_{m_C + 1}, V_{m_C + 1})$, with the test score $R_{m_C + 1} = | V_{m_C + 1} - \hat{\mu}(U_{m_C + 1}) |$. Under Assumption~\ref{ass:scores} on the sorted scores $R_1 < \cdots < R_{m_C}$, the split conformal predictor from \eqref{eq:quantile_form}, specialised to $\delta \in (0,1)$, constructs the prediction interval
\begin{equation}
    \Gamma^\delta_{m_C}(U_{m_C + 1}) = \{ v \in \mathbb{R} : | v - \hat{\mu}(U_{m_C + 1}) | \leq q_{1 - \delta} \},
\end{equation}
where $q_{1 - \delta} = \mathrm{Quantile}_{1 - \delta}( \{ R_j : j \in \mathcal{I}_C \} \cup \{ +\infty \} )$ is the empirical $(1 - \delta)$-quantile of the calibration residuals, computed as $q_{1 - \delta} = R_{(p)}$ with $p = \lceil (1 - \delta)(m_C + 1) \rceil$ and $R_{(1)} \leq \cdots \leq R_{(m_C)}$ the ordered calibration scores. By Theorem~\ref{thm:split_validity}, exchangeability of $\{ X_i \}_{i=1}^{N+1}$ ensures conservative validity:
\begin{equation}
    \mathbb{P}_{N+1} \big\{ \phi^K(X_{N+1}) \in \Gamma^\delta_{m_C}(U_{N+1}) \big\} \geq 1 - \delta,
\end{equation}
providing a distribution-free probabilistic guarantee on the performance metric directly, without reliance on structural assumptions beyond the solver's fixed-point formulation.

This interval bounds $\phi^K(X_{N+1})$ symmetrically around the predicted value $\hat{\mu}(U_{N+1})$, enabling adaptive control of computational budgets: for a new blurry image $x_{N+1}$, if the lower bound $\hat{\mu}(U_{N+1}) - q_{1 - \delta} > \varepsilon$ for a tolerance $\varepsilon > 0$, allocate additional iterations beyond $K$; otherwise, accept $y^K(x_{N+1})$ as sufficiently accurate with at least $1 - \delta$ confidence.

Empirical coverage on a held-out validation set $\mathcal{I}_\mathrm{val}$ verifies $\frac{1}{|\mathcal{I}_\mathrm{val}|} \sum_{j \in \mathcal{I}_\mathrm{val}} \mathbf{1}_{\{ \phi^K(x_j) \in \Gamma^\delta_{m_C}(U_j) \}} \approx 1 - \delta$, guiding $\delta$ selection.

Unlike PAC-Bayes bounds in \cite{RSBS25}, which generalise expected indicator losses over learned weights via posterior complexity, this split conformal approach directly calibrates the residual metric for the fixed classical solver, yielding unconditional finite-sample guarantees without optimisation over hyperparameters or sampling from posteriors.
