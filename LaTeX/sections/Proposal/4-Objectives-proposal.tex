\paragraph{Objectives}

To address these shortcomings, we propose leveraging Conformal Prediction (CP) as a flexible, distribution-free alternative for providing probabilistic performance guarantees of the form~\eqref{eq:probabilistic_guarantee} to parametric optimisation problems solved with first-order methods. CP is a modern, lightweight statistical tool that enables the construction of finite-sample probabilistic guarantees which hold with high confidence for any underlying parameter distribution. It provides calibrated prediction sets around performance metrics without requiring strong prior assumptions on the data-generating process. In our context, CP can be applied to derive rigorous, data-driven confidence intervals for metric $\phi^k(x)$, using non-conformity scores derived from algorithm executions to quantify uncertainty in convergence behaviour for unseen parameters $x \in \mathcal{X}$. Specifically, we intend to:
\begin{itemize}[noitemsep]
\item Develop a theoretical foundation by modeling the data-driven performance analysis as a CP problem, identifying suitable learning paradigms (e.g., inductive or transductive) and designing non-conformity functions tailored to optimisation metrics like suboptimality or residual norms.
\item Derive specialised bounds that exploit structural information about the algorithm and problem class, to tighten the guarantees and improve efficiency over other existing approaches.
\item Conduct extensive numerical validation on real-world applications, including optimal control, image deblurring, and signal processing tasks, with comparisons to state-of-the-art probabilistic guarantees from PAC-Bayes and Scenario Approach frameworks.
\item Explore algorithm design implications, for instance, by tuning hyperparameters like step sizes in proximal gradient descent to optimise conformal coverage or minimise prediction set sizes.
\item Create an open-source Python toolbox implementing the proposed conformal prediction methods for optimisation performance analysis, facilitating easy adoption and extension by researchers.
\item Investigate automated code generation using large language models (LLMs) (e.g., via tools like SWE-agent) to streamline the implementation of custom conformal predictors for user-defined optimisation scenarios.
\end{itemize}

By achieving these objectives, this project will advance the state of the art in data-driven performance guarantees for parametric optimisation, offering a robust and accessible framework that enhances reliability in real-time and safety-critical applications. This study will add to a growing catalogue of practical applications of CP, which has been a central target of analysis in the control engineering and ML communities. Ultimately, the integration of CP promises to empower practitioners with tighter, more intuitive, distribution-free bounds that do not rely on a high number of samples.
